# Leaves of Blocks reuse audit

Reviewed 2026-09-30 for the [preflight spike](../spikes/preflight-open-source-reuse.md), Epics 08–09. Decision: **use as a pattern/reference**, with no upstream code, assets, build tooling, or runtime dependency added. The useful small slice is drag-to-grid placement geometry with regression tests. The full application conflicts with the product's prohibition on analytics and accounts, even though Game Center is optional and analytics are local.

## License, assets, and dependency boundary

The root [MIT license](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LICENSE) names Tim Veil, 2026. A later source extraction must retain that copyright notice and the full permission/warranty text with substantial copied portions, pin the source revision, and record local modifications. No extraction is approved by this report.

The repository asserts a project-wide MIT license, but the inspected asset catalogs provide image filenames/scales without individual provenance records. Assets include app icons, tree backgrounds, Whitman portraits, an acorn SVG, repository logos, an App Store badge, localized quotations, and store copy. No separate asset license or provenance inventory was found. Typography uses system SwiftUI fonts; no bundled font files were found. Root MIT coverage alone does not establish third-party rights in portraits, translations, or badges. Do not copy those assets, names, layouts, translations, levels, or store presentation; the roadmap independently requires original title identities. Asset/name clearance is **not passed**. See [asset catalog](https://github.com/timveil/leaves-of-blocks/tree/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Assets.xcassets) and [typography](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Resources/Theming/Typography.swift).

## Runtime data flows and privacy findings

1. **Gameplay analytics are always part of normal gameplay.** [GameState](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Models/Game/GameState.swift) starts/resets a [PlayerBehaviorTracker](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Logic/Game/PlayerBehaviorTracker.swift), records board efficiency, fragmentation and strategic opportunities after placements, and finalizes score/time/difficulty/strategy/challenge/fallback metrics at game-over. Histories are bounded in memory; undo snapshots also carry tracker state. [GameService](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Game/GameService.swift) sends completed records to [CoreDataManager](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Data/CoreDataManager.swift), which persists analytics and serves history/statistics screens. Local analytics still violates this project's no-analytics rule. Removing a statistics screen would not remove collection or persistence.
2. **Resume saves are separate local JSON.** [InProgressGameStore](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Data/InProgressGameStore.swift) atomically writes grid, active blocks, counters, difficulty, time and saved-at values to Application Support. It omits tracker histories, which restart on resume. Core Data uses `NSPersistentContainer`, not a CloudKit container. No iCloud entitlement or cloud-sync implementation was found. OS backup behavior was not tested; app-local storage alone is not evidence of backup exclusion.
3. **Game Center can perform network/account activity.** [Preference](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Configuration/GameCenterPreference.swift) defaults false in UserDefaults, but the app has a [Game Center entitlement](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/LeavesOfBlocks.entitlements). Opt-in triggers [GameCenterService](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Game/GameCenterService.swift) authentication via `GKLocalPlayer`, leaderboard score submission and achievement reporting derived from session metrics. Failed submissions are queued in [UserDefaults](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Game/PendingGameCenterSubmissionStore.swift) for retry after authentication. Disabling the preference stops submissions but does not sign out. The [privacy manifest](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Resources/PrivacyInfo.xcprivacy) declares linked user ID/gameplay content for functionality and no tracking. It must not be copied as this product's manifest.
4. **Outbound browser handoff exists.** [AboutView](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Views/About/AboutView.swift) opens the author's LinkedIn/website with `utm_source`, `utm_medium` and `utm_campaign` parameters. These are user-initiated external URL handoffs, not an embedded HTTP client; they still carry attribution parameters and are outside the allowed reuse slice.
5. **Logging is local system logging.** [BuildConfiguration](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Services/Configuration/BuildConfiguration.swift) uses `os.Logger` with public messages; Debug permits debug/info and Release warning/error. Gameplay metrics appear in debug/info messages. No crash-reporting/analytics SDK, ad/purchase SDK, direct URLSession/WebKit client, push registration, ATT request or sensitive permission prompt was found by import/API/entitlement searches. GameKit remains a real network-capable path despite that negative direct-HTTP search.
6. **Developer tooling has separate external flows.** [AIHelper](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/fastlane/AIHelper.rb) can send commit/changelog material to Anthropic when configured with an API key. [Fastfile](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/fastlane/Fastfile) and [release helpers](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/fastlane/release_helpers.rb) support App Store Connect uploads, metadata changes, signing and Git release mutations. They are not bundled app flows and were inspected, not executed. The direct Xcode build bypassed them. The project had no custom shell build phase or SwiftPM plugin to execute.

To exclude the unwanted features, keep the reuse boundary at geometry/value types/tests. Do not copy `GameState`, `UndoSnapshot`, `PlayerBehaviorTracker`, `GameService`, Core Data history/statistics models, Game Center services/preferences/pending store, app entitlements, manifest, About screen or release tooling. They are title features, but analytics is structurally woven through the state/save path rather than a removable SDK toggle.

## Small reusable slice and quality patterns

**Candidate vertical slice:** tray drag → finger-lift adjustment → nearest legal board-cell preview → placement command → visual confirmation. [BoardLayout](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Views/Game/BoardLayout.swift) isolates off-board-safe search ranges, adaptive lift near the top edge, placed-block center calculation, and nearest-valid-position selection with an injected `canPlace` closure. [BoardLayoutTests](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocksTests/BoardLayoutTests.swift) includes 20 test declarations covering these helpers, including a historic far-off-board range crash. [BoardView](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/Views/Game/BoardView.swift) and [GameSceneBridge](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocks/SpriteKit/GameSceneBridge.swift) show the SwiftUI-input/SpriteKit-preview seam, but both reference the full title state and should be studied rather than lifted wholesale.

Estimated work, after Spike 06 proves the game-module seam: **2–3 developer days** for an original tiny integration or narrow MIT extraction (0.5 day geometry/value-type adaptation, 0.5–1 day own input/preview/commit wiring, 1 day regression tests and touch/pointer checks). Add **1–2 days** to design and verify accessible non-drag placement, which the inspected board does not establish. Geometry alone is roughly half a day to adapt and half a day to test. These estimates exclude full game rules, art, save migration and content.

Accessibility evidence is narrower than upstream's README claim: labels and identifiers exist, several effects gate on Reduce Motion, combo announcements use `UIAccessibility.post`, and typography uses Dynamic Type styles. The inspected tray is still implemented with `DragGesture`; no board placement accessibility action or alternative cell-selection flow was found. Labels/test identifiers do not prove playable VoiceOver interaction. Verify independently in Epic 08, including reduced motion, large text, switch/keyboard/pointer and non-drag placement.

Localization is a useful process reference: [.locales](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/.locales) maps ten App Store locales to app locales, and [tests](https://github.com/timveil/leaves-of-blocks/tree/151ec8334423dd5023f1e27e9cb17e1f840a2193/LeavesOfBlocksTests) check format placeholders, escaping, grade keys and cited verses. Study registry-consistency checks and placeholder tests; create original product strings. [iOS CI](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/.github/workflows/ios.yml) builds once then separates unit/UI jobs, retains result artifacts, bounds run time, and shards UI tests. [build.sh](https://github.com/timveil/leaves-of-blocks/blob/151ec8334423dd5023f1e27e9cb17e1f840a2193/scripts/build.sh) also contains simulator-wide shutdown in its `run` path; that path was not executed.

## Maintenance and reversal

Git history shows recent September 2026 generator correctness/performance tests, screenshot-runtime validation, and dependency maintenance. Local `git shortlog -sn HEAD` reported 608 commits attributed to Tim Veil, 35 to Dependabot and 5 to Claude: active work, but concentrated maintenance. Tags include v2.1.0, v2.0.7 and earlier; current project marketing version is 2.1.1. These are repository observations, not a support commitment or proof that hosted CI is currently green.

Expected owner: **gamecore's Epic 09 title maintainer**, with the Epic 08 maintainer responsible for accessibility/localization/release checks. Reference-only use creates no upstream update obligation and no data/schema coupling. Reversal now is removal of this recommendation, with no runtime cost. If a later narrow geometry extraction is approved, budget about 0.5–1 day to replace it behind the same value-type/placement interface; keep copied tests and notices until copied material is removed. Reopening full-app adoption would require a fresh privacy review, asset provenance, platform-port estimate and runtime verification; a successful simulator build alone is insufficient.
