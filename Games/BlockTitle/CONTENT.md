- Content: the title name Blocky Marty, chosen by the project owner on 2026-10-21; menu, play, teaching and result text; 30 original boards in three chapters; and SpriteKit blocks in four system colors, each with its own white mark (circle, square, triangle, diamond). The [app icon](Assets.xcassets/AppIcon.appiconset) is a 3×3 board of rounded blocks in the four colors on a dark background, rendered by `scripts/app-icon.py --blocks 1E2433 E8615A 2BB3A6 F2C14E 8E6CD9`. There are no imported images, sounds, fonts or translations; shell feedback uses the shared authored tones.
- Rules: [ADR-010](../../roadmap/decisions/ADR-010-block-match-rules.md). Select a group of two or more orthogonally connected blocks of one kind to clear it; blocks above fall straight down and columns never shift. A board is cleared when empty; a stuck board stays in play with Undo and End board. Each clear of n blocks scores n × (n − 1), and only a cleared board's score counts toward the level's best.
- Creator and date: project contributors using Claude Code, 2026-10-19 (reference slice) and 2026-10-21 (complete level set). This is original material authored for this repository; no upstream code, levels, artwork or names were used as inputs. Collapse-style group clearing is a common mechanic, not copied expression.
- Creation method: `intro-01` and `intro-02` are written by hand (seeds 201 and 202 only identify them); the authoring solver records a clearing sequence for each. The other 28 boards are generated by reverse construction from the seeds in the level plan: starting from an empty grid, the generator inserts groups that the forward move clears exactly, so each board ships with the clearing sequence that built it. Each generated board also meets its plan's difficulty band: the share of 1,000 uniformly random plays that clear it, which falls from about 0.64 on `intro-03` to about 0.02 on `final-10`. `BlockContentValidator generate Games/BlockContent/level-plan.json <directory>` rebuilds every level and the catalog, and `test-content-cli.py` checks that the result matches the bundled files byte for byte. The random-play rate orders difficulty; it is not a measure of how hard people find a board, which needs play testing.
