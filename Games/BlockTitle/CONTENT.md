# Content record: Block Match reference slice

- Local paths: [BlockModule.swift](BlockModule.swift), [BlockTitleApp.swift](BlockTitleApp.swift), and the [BlockContent resources](../BlockContent/Sources/BlockContent/Resources) and [rules](../BlockContent/Sources/BlockContent/BlockRules.swift).
- Content: the working title Block Match, menu and result text, two original 3×3 and 4×4 boards (`intro-01`, `intro-02`), and SpriteKit blocks in four system colors, each with its own white mark (circle, square, triangle, diamond). The app icon is a 3×3 board of rounded blocks in the four colors on a dark background, rendered by `scripts/app-icon.py --blocks 1E2433 E8615A 2BB3A6 F2C14E 8E6CD9`. There are no imported images, sounds, fonts or translations; shell feedback uses the shared authored tones.
- Rules: select a group of two or more orthogonally connected blocks of one color to clear it; blocks above fall into the gap. A board is cleared when empty and ends without progress when blocks remain but no group of two does. Each clear of n blocks scores n × (n − 1). These are the reference slice's rules; [Epic 09A](../../roadmap/epics/09a-block-title.md) records the complete title's rules.
- Creator and date: project contributors using Claude Code, 2026-10-19. This is original material authored for this repository; no upstream code, levels, artwork or names were used as inputs. Collapse-style group clearing is a common mechanic, not copied expression.
- Creation method: board layouts written by hand and checked with the content validator's solver: every shipped board must be clearable, and `intro-02` also has a losing first choice. Seeds 201 and 202 identify the boards; these rules use no randomness.
- Rights and redistribution: project-authored content is contributed under the repository's [MIT license](../../LICENSE). Apple frameworks, SF Symbols, system fonts and system colors remain platform inputs under Apple's terms. The content package also carries the [SplitMix64 notice](../BlockContent/Sources/BlockContent/Resources/SplitMix64-NOTICE.txt), because every app links `GameCore`'s deterministic generator.
- Review: package tests replay each board's solution fixture and the losing line; app-hosted and UI tests play the first board by touch and by the accessible controls. Approved as an Epic 07 reference slice, with no claim that the working title, art or two boards are a finished game.
